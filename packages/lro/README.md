# alis-build-lro

Long-running operations for services on the [Alis Build](https://alisx.com/build)
platform: create one, persist it, resume it through a named handler, and serve
the standard `google.longrunning.Operations` API.

```bash
pip install alis-build-lro
```

```python
from alis.build import lro
```

Full usage documentation lands with the rest of this package.
